Privacy policy

Last updated: October 4, 2026

CS Agent is a private tool that one eBay seller uses to manage customer messages on their own eBay account. It is not offered to the public.

What the app accesses

With the seller's permission, granted through eBay sign-in, the app reads:

  • messages that buyers send to the seller on eBay
  • order, shipping, and tracking details for the seller's orders
  • the seller's listing details

How it is used

The data is used only to draft and send replies to buyers through eBay messaging, and to alert the seller about messages that need personal attention. Message text and order facts are processed by AI service providers to classify messages and draft replies.

Storage and sharing

Data is stored in the seller's own database. eBay access tokens are stored encrypted. Data is not sold, and is not shared except with the service providers needed to run the app, as described above.

Deletion

Data is kept only as long as it is needed to handle buyer conversations. The seller deletes an eBay user's data on request, including deletion requests that eBay passes on.

Contact

Buyers can contact the seller through eBay messaging.
